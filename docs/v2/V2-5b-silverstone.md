# V2-5b: Silverstone
Layout order: Abbey (fast right-left), Farm, Village (right), The Loop (tight left), Aintree
(left), Wellington Straight, Brooklands (left), Luffield (long right), Woodcote (right), Copse
(fast right), Maggotts (left-right), Becketts (right-left), Chapel (left), Hangar Straight
(long), Stowe (right), Vale (left), Club (right), back to Abbey.

tower, gravel run-off areas as decoration, distant trees and hedges, soft overcast sky with
procedural clouds. Day: diffuse grey-white light, soft shadows. Night: tall floodlights.
